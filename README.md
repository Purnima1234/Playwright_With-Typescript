## Chapter Overview

### Day 1 - Basics
- Introduction to JavaScript basics

### Chapter 2 - JavaScript Basics
- **05_Java_Basics.js** — JavaScript keywords and basic syntax

### Chapter 3 - Identifiers & Literals
- **06_Identifier_Rules.js** — All 7 identifier rules with valid/invalid examples
- **07_Identifier_Rules_part2.js** — Naming conventions: Camel Case, Snake Case, Pascal Case, Upper Snake Case, Kebab Case, Hungarian Notation
- **08_comments.js** — Single-line and multi-line comments in JavaScript
- **VSCode_Keyboard_Shortcuts.md** — VS Code keyboard shortcuts reference for Windows

### Chapter 4 - JavaScript Variables, Functions & Hoisting
- **09_Var.js** — Introduction to `var`, `let`, and `const` declarations
- **10_funtions.js** — Functions: definition, calling, and reusable code
- **11_var_explained.js** — `var` and function scope explained
- **12_let_Keyword.js** — `let` keyword: block scope, reassignment, no redeclaration
- **13_Const_Explained.js** — `const`: block-scoped constants that cannot be reassigned
- **14_var_functionscope.js** — `var` function scope with examples
- **15_let_Scope.js** — `let` block scope with examples
- **16_Hoisting.js** — Hoisting: declarations moved to top of scope, undefined initializations
- **17_Hoisting_Functions.js** — Hoisting behaviour with functions and `var`
- **18_let_Hoisting.js** — `let` hoisting and the Temporal Dead Zone (TDZ)
- **19_let_Hoisting_block.js** — `let` hoisting within block scope
- **20_let_const.js** — Comparing `let` and `const` behaviour
- **21_JRQA.js** — JavaScript review questions and answers

### Chapter 5 - Literals
- **22_literals.js** — Introduction to JavaScript literals
- **23_null_undefined.js** — `null` and `undefined` literals
- **24_null.js** — Deep dive into `null`
- **25_literal_all.js** — All literal types: number, string, boolean, null, undefined, object, array
- **26_Literal_Number_all.js** — Number literals: decimal, binary, octal, hexadecimal, BigInt
- **27_String.js** — String literals and escape sequences
- **28_Template_literals.js** — Template literals with `${}` expressions and multi-line strings
- **29_Backtick_single_double.js** — Backtick vs single vs double quotes

### Chapter 6 - Operators
- **30_operator.js** — Assignment operator
- **31_Arithmatic_operator.js** — Arithmetic operators: `+`, `-`, `*`, `/`
- **32_Modulus_operator.js** — Modulus operator `%` (remainder)
- **33_Expo_op.js** — Exponentiation operator `**`
- **34_IQ.js** — Compound assignment operators: `+=`, `-=`, `*=`, `/=`
- **35_comparison.js** — Comparison operators: `>`, `<`, `>=`, `<=`
- **36_Comparison_strictVSLoose.js** — Loose equality `==` explained
- **37_looseVSStrict.js** — Loose vs strict comparison examples
- **38_Confusing_comparison.js** — Confusing `==` vs `===` cases: null, NaN, coercion, objects
- **39_logicalOperators.js** — Logical operators: `&&`, `||`, `!`
- **40_string_con.js** — String concatenation using the `+` operator
- **41_tarnary_Opertor.js** — Ternary operator `condition ? expr1 : expr2`
- **42_typeOPerator.js** — `typeof` operator
- **43_increment_decrement_op.js** — Increment `++` and decrement `--` operators
- **44_null_operator.js** — Nullish coalescing `??` and optional chaining `?.` operators
